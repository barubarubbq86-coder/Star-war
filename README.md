# 星の砦 — Phase 2.1

Phase 2正式ZIPを基に、追加敵7体を見つけて選択しやすくした修正版です。

1. ホームの「新しい敵7体を選んで遊ぶ」を押す。
2. 画像付きのモブ6体を選び、右側（スマートフォンでは下）のボス候補でぶんぶん先生を選ぶ。
3. ステージ名・出現間隔・ボスの出現条件を決め、「このステージを作る」を押す。
4. 作成されたステージの「出撃」を押す。

「敵・自作敵」でも7体の絵と名前を確認し、直接ステージへ設定できます。基本8ステージの出現敵は従来どおりです。

GitHub PagesへはZIPの中身をassetsフォルダごと配置してください。公開・更新手順はUPDATE.md。保存データは端末内に保持します。実ブラウザ操作・Android実機試験・実PWA起動は未実施です。詳細はVALIDATION.mdをご確認ください。

- CAUSE.md: 原因調査とID対応
- CHANGELOG.md: 差分
- VALIDATION.md / TEST_RESULTS.json: 試験・未確認事項
- ANDROID_CHECKLIST.md: 実機確認
- CHARACTER_ASSETS.md / CHARACTER_STATS.md / PROVISIONAL.md: Phase 2から維持した画像・能力値・仮設定
