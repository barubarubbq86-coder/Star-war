# 星の砦 — Phase 3「七傑の侵攻」

Androidで遊べた正式Phase 2.1 ZIPを基に、七傑だけの基本28面・5段階オーラ・章選択を追加したHTML/CSS/JavaScriptのPWAです。ステージから次に進み、自作ステージは同画面の「自作ステージを遊ぶ」から開けます。「敵・自作敵」では旧20体と七傑を従来どおり選択できます。

ZIPを展開すると直下に `index.html`、`stages.js`、`characters.js`、`game.js`、`sw.js`、`assets/` があります。その階層のまま**既存**GitHub Pagesの公開元へコピーします。URLやサイトデータを変えません。詳しくはUPDATE.md。

- STAGE_DESIGN.md: 全28面と1面ごとのモデル試験
- ENEMY_BALANCE.md: 基準値と7体×5段階
- SAVE_MIGRATION.md: 旧8面進行・v7保存の継承
- VALIDATION.md: 実施したテストと限界
- ANDROID_CHECKLIST.md: 実機確認
- CHANGELOG.md: 差分

実ブラウザとAndroid実機の操作、実PWAオフライン起動はこの開発環境では未確認です。ユーザーの実機確認後に正式版へ進めるか判断してください。
