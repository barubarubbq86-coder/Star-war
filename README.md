# スターリング・シージ：Android対応・GitHub Pages版

国旗かるたと同じように、GitHub PagesのURLからブラウザで遊び、Android Chromeからホーム画面にインストールできるWebアプリ（PWA）です。APKやPlayストアのアプリではありません。Pythonやサーバーの起動は不要です。基本の味方15体・敵20体に加え、自作の味方と敵を各20体まで保存できます。8ステージ、ボス、ガチャ、育成、自作ステージ、ペイント、緑背景の手描き画像の取り込みを含みます。

### すでにこのPages版を公開している場合

同じリポジトリの `index.html`、`game.js`、`sw.js`、`manifest.webmanifest`、`icon-192.png`、`icon-512.png`、`README.md`、`ASSET_NOTICE.md` を今回のZIPの8ファイルで上書きしてコミットしてください。**同じURLで開けば、ブラウザ内のキャラ・絵・進行状況はそのまま読み込まれます。** 最初に新しい画面が出ない場合は、オンライン状態でページを再読み込みしてください。サイトデータを削除しないでください。

## GitHub Pagesにアップロードする

**以前の、敵画像入りの非公開リポジトリを公開に切り替えないでください。** 画像は過去のコミットにも残ります。GitHub上で新しい **Public** リポジトリを作り、このZIPの**中身**を使います。ZIP自体はアップロードしません。

1. このZIPを展開します。中にある `index.html`、`game.js`、`sw.js`、`manifest.webmanifest`、`icon-192.png`、`icon-512.png`、`README.md`、`ASSET_NOTICE.md` を確認します。`assets` フォルダは入っていません。
2. 新しいリポジトリの **Add file → Upload files** で、展開した8ファイルをすべて選んでアップロードし、**Commit changes** を押します。`index.html` がリポジトリの一番上にある状態にします。
3. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch**、ブランチ **main**、フォルダ **/(root)** を選び **Save** を押します。
4. **Actions** のPagesの処理が完了したら、**Settings → Pages** に表示されるURLを開きます。表示されるまで数分かかることがあります。

一般的なURLは `https://ユーザー名.github.io/リポジトリ名/` です。GitHub FreeではPages用のリポジトリはPublicにする必要があり、Pagesのサイトはインターネット上で公開されます。ユーザー名やリポジトリ名に個人情報を入れないでください。

## Androidにインストールする

1. Androidの **Chrome** で公開したGitHub PagesのURL（`https://...`）を開きます。画面が表示されるまで待ち、一度ゲームを操作します。
2. Chrome右上の **⋮** をタップし、**「アプリをインストール」** または **「インストールしてショートカットを作成」→「インストール」** を選びます。表示名はChromeの版によって異なります。
3. ホーム画面の **「星の砦」** アイコンから起動します。横向きにすると戦闘画面を広く使えます。縦向きでも操作できます。

この方式はWebアプリのインストールです。最初のアクセスとアップデートにはネット接続が必要です。ゲーム本体は初回アクセス後に端末へキャッシュされ、保存が残っていればオフラインでも開けますが、AndroidやChromeがキャッシュを削除した場合は再度接続が必要です。PCからのセーブや絵はAndroidへ自動同期されません。

## 敵画像を自分の端末に設定する

初めは20体ともオリジナルの仮キャラで遊べます。手元にある敵画像を使いたい場合は、公開済みのゲームを開いて上部の **自作キャラ 敵** → **既存の敵20体の名前・画像を編集** へ進みます。前の画像入りZIPをPCで展開済みなら、その中の `assets/enemies` にある20枚を選べます（画像をGitHubへアップロードする操作ではありません）。

- **敵画像をまとめて読み込む**で、`M-01.png`、`M-14.png`、`B-1.png`、`B-20.png` のような名前の画像を複数選びます。数字とM/Bで敵へ割り当てます。対応している枠はモブ15、ボス5の計20体です。
- 名前が合わない画像は、該当キャラの **画像を設定** から個別に選びます。**仮キャラに戻す**で取り消せます。
- 画像はブラウザ内で最大512pxに縮小し、メタデータを除いてIndexedDBへ保存します。**GitHubにアップロードされず、別の端末には自動で移りません。** PCとスマホで使うなら、それぞれの端末で読み込んでください。
- 1枚8MB以下のPNG・JPEG・WebP、幅と高さは各4000px以下。端末の空き容量やブラウザ設定によって保存できない場合があります。

いらすとやの画像を使う場合はご自身の端末で読み込み、画像入りの旧ZIPや `assets/enemies/` を新しい公開リポジトリへアップロードしないでください。旧リポジトリをPublicへ変更することも避けてください。

## 遊び方と保存

- ホームの **今すぐテストプレイ** で開始。味方を生産し、働き手を増やしてお金を作り、敵城のHPを0にします。画面を左右にドラッグするとスクロールします。戦闘画面を指2本で広げると縮小、近づけると拡大します。**全体を見る** ボタンで両方の城を同時に表示できます。50%～200%の表示倍率を画面下のボタンでも調整できます。
- 上部メニューの **設定** で、戦闘中の味方と敵のキャラクターHPを「バーだけ」「数字だけ」「バーと数字」「表示しない」から選べます。数字は現在HP/最大HPです。設定は端末内に保存され、城HP表示には影響しません。
- **ユニット** で最大8体を編成・育成します。出撃ボタンのコストは自作の味方で設定した値を使います。
- **ペイント**の「味方・敵」で所属を決め、「新しい味方／敵を作る」を保存先にして絵を保存します。作ったキャラは **自作キャラ 味方／敵** に表示され、名前や能力を編集できます。既存のキャラを選ぶと、保存済みの絵をペイントに読み込んで描き直せます。
- **自作キャラ 味方** では名前、HP、攻撃力、ユニットコスト、移動速度、射程、攻撃間隔、生産クールタイム、範囲攻撃を直接編集できます。画像なしで作ることもできます。**自作キャラ 敵** では名前、HP、攻撃力、移動速度、射程、攻撃間隔、大きさ、範囲攻撃、モブ／ボスを編集できます。新しい敵は初めはモブです。味方・敵ともHP、攻撃力、移動速度は上限なしで、1以上の有限な数値を保存できます。その他の能力は従来の入力範囲に収めます。極端に大きい値はブラウザの数値精度に従って扱われます。
- 緑背景の画像取り込みは **自作キャラ 味方／敵** の画面下から使えます。味方の既存15体にも絵を設定できます。敵の既存20体の名前変更・画像設定・一括取り込みは **自作キャラ 敵** の「既存の敵20体の名前・画像を編集」を開きます。旧「組み合わせ工房」の見た目のパーツ編集は終了し、絵の編集にはペイントを使います。
- **ステージ** の「自作ステージを作る・編集する」で名前を付け、登場するモブを選んで**種類ごとに出現間隔**（0.1秒以上）を入力できます。モブなしのステージも作れます。最初の出現もその秒数後です。ボスは候補から選び、**開始から指定秒数後**または**敵の塔が味方に攻撃された時**に一度だけ出現させます。作ったステージは一覧の「ステージを編集」から名前や設定を変更でき、基本ステージのクリアを待たずに出撃できます。基本の8ステージの出現方式は変わりません。
- 自作した敵のモブ／ボスは **自作キャラ 敵** の「種類（自作ステージの配置先）」で変更できます。種類を変えた敵が既存の自作ステージに配置されていた場合は、そのステージの配置を有効な候補へ更新します。以前に作成したステージは名前と敵を引き継ぎ、モブ別の初期出現間隔を4.5秒、ボスの初期出現時間を31秒として読み込みます。端末が重くならないよう、同時に生存するモブは自作ステージで最大120体です。
- ペイントの **塗りつぶし** は、タップした場所とつながっている同じ色の範囲に、選んだ色を塗ります。外枠が閉じていないと外側まで塗られるので、**戻す**で取り消してください。ペン・消しゴム・塗りつぶしは共通の戻す／やり直すに対応します。**下書きを端末に保存** ボタンもあります。
- 味方・敵の手描き画像は専用メニューで緑背景の画像を取り込むか、アプリ内のペイントで作れます。被ダメージが最大HPの20%に達するたび2回跳ねます。
- XP、星缶、進行状況、自作キャラの名前と能力、自作ステージはlocalStorage、味方・敵の絵と下書きはIndexedDBに**使用中のブラウザのホスト単位**で保存します。ブラウザのサイトデータ削除やホスト名の変更で使えなくなる場合があります。旧オフライン版 `127.0.0.1:8765` のデータは自動では移りません。
- 自作キャラの能力や編成などは作成・変更時に自動保存されます。**設定** の **今すぐ端末に保存** はゲームデータを明示的に保存します。ペイントの下書きは描いたあと自動保存され、**下書きを端末に保存**で即時保存できます。完成した絵は **この絵をキャラに設定** で保存します。画像やゲームデータはGitHubへ自動送信されません。ブラウザのデータ消去に備えるファイルへのバックアップ機能はありません。
- 初回はネット接続が必要です。正常に開けたあとゲーム本体のファイルをブラウザがキャッシュするため、同じ端末・同じURLならオフラインでも開ける場合があります。ただしブラウザが保存領域を削除すると使えなくなるため、常時オフラインでの利用には旧オフライン版が確実です。

## 安全性

アプリ本体に広告、解析、アカウント、チャット、外部CDN、送信処理はありません。通信先はゲーム本体を配信するGitHub Pagesの同一ホストに制限しています。絵やセーブをアプリから送信する処理はありません。アプリアイコンと画面のファイルだけをオフライン用にキャッシュします。ただしPagesを開く際の通信では、GitHub側にアクセス情報（IPアドレスなど）が伝わります。共有端末の同じブラウザでは他の利用者も保存した絵を見られます。

複数のGitHub Pagesアプリを `同じユーザー名.github.io` で公開すると、**リポジトリのパスが違ってもブラウザの保存領域は同じホストで共有**されます。そのホストで動く別のアプリのJavaScriptにも保存内容を読む権限があります。ゲームだけの保存領域が必要なら、ゲーム専用のドメインまたは専用GitHubアカウントのPagesを使用してください。別アカウントでもPagesを閲覧する際にはインターネット通信が発生します。

サイトのURLや独自ドメインを変更すると、ブラウザ内の保存領域が別になります。画像とセーブが重要な場合、変更前に元のURLを残してください。利用規約については `ASSET_NOTICE.md` も参照してください。
